# 🔎 Timpi Node Checkers

Discord slash commands for checking the status of your Timpi nodes. Results are **ephemeral** — only you see them.

> [!IMPORTANT]
> You need the **Verified Human** role on the Timpi Discord to use these commands.

## How it works

1. Type the command in **any channel** (you must have the **Verified Human** role).
2. A **popup** appears — enter your **GUID** (and **Port** when required).
3. Press **Submit** → you see a **private** result.

Other users can't see your GUID or status.

## 🙋 FAQ

**Where do I run these commands?**
In the **Timpi Discord server**, in **any channel** as long as you have the **Verified Human** role.

**Can other people see my GUID or my results?**
No — the checkers use **ephemeral responses**. Only you see them.

**Do I need to paste my GUID into chat?**
No. The popup appears when you type the command, and the GUID stays in the popup — never in the chat history.
